# Dashboard Monitor Skill

This skill allows an OpenClaw agent to monitor its own performance, costs, and health by querying the OpenClaw Dashboard API.

## Capabilities
- Check system health (Gateway PID, Uptime, Memory)
- Monitor token usage and costs
- List active subagents and their status
- View recent alerts generated by the system

## Tools

### dashboard_get_status
Fetches the full status from the dashboard API.

**URL**: `http://localhost:8080/api/status`

## Implementation Details (Learned from Data Refresh Script)

### 1. Gateway Process Monitoring
The dashboard monitors the `openclaw-gateway` process using `pgrep` and `ps`. 
It reports:
- **Status**: Online/Offline
- **Memory**: RSS usage (Alerts if > 500MB)
- **Uptime**: How long the gateway has been running.

### 2. Cost Analysis
The dashboard parses `*.jsonl` transcript files to calculate real-time costs even before they are aggregated by the core.
- **High Cost Alert**: Triggers if daily cost exceeds $20.

### 3. Subagent Tracking
Automatically detects defined bots in `openclaw.json` and active runs in `subagents/runs.json`.

## Usage Example
"Check if my memory usage is okay and what is my total cost today?"
-> Agent calls `dashboard_get_status` and analyzes the `system.gateway_memory` and `detailed_usage` fields.
